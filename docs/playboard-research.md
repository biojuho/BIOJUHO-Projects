# playboard.co 조사 — 유튜브 인기순위를 어떻게 얻고, 우리가 쓸 데가 있는가

작성 2026-08-07 · Claude · 실측 기반(그날 받은 페이지를 직접 파싱)

## 한 줄 결론

**얻는 건 쉽다. 쓸 데가 애매하다.** 접근·파싱은 걸림돌이 없지만, 이 사이트가 매기는 순위는
조회수 증가량이라 광고와 뮤직비디오가 상위를 차지한다. 우리가 찾는 "X에 올릴 커뮤니티 소재"와는
다른 것을 잰다.

## 1. 접근 — 막는 게 없다

`robots.txt`는 `User-agent: *`에 `Allow: /`를 준다. 막는 대상은 SEO 크롤러들(Yandex, Semrush,
Ahrefs, BLEXBot, dotbot, grapeshot, Amazonbot, MauiBot, SeekportBot)이고, Googlebot에만
`/video/`와 `/en/video/`를 금지한다. 우리는 `*`에 해당하며 제한이 없다.

Cloudflare 챌린지도, 로그인도, API 키도 필요 없다. **aagag가 막힌 것과는 정반대다.**

## 2. 획득 방식 — Nuxt SSR이라 HTML에 답이 다 있다

화면은 Nuxt로 그리지만 **서버가 이미 렌더링해서 내려준다.** 그래서 API를 찾을 필요가 없고
`curl` 한 번이면 된다. (moamoa·todaybeststory는 같은 SPA인데 데이터를 클라이언트에서 부르기
때문에 HTML이 비어 있었다 — playboard는 그 반대다.)

한 행이 `<tr class="chart__row">`이고, 그 안에 필요한 게 전부 들어 있다:

| 항목 | 위치 |
|------|------|
| 순위 · 변동 | `td.rank` → `div.current`, `div.fluc`(`NEW` 등) |
| 영상 ID · 채널 ID | `td.thumbnail a[href="/video/<11자리>?channelId=<UC…>"]` |
| 썸네일 | `div[data-background-image="//img.youtube.com/vi/<ID>/mqdefault.jpg"]` |
| 제목 | `td.title a.title__label > h3` |
| 해시태그 | `ul.title__tags li.ttags__item` |
| 게시일 | `div.title__date` (예: `2026.08.05`) |
| **조회수 증가량** | `td.score span.fluc-label` (예: `30,268,586`) |
| 채널명 · 구독자 | `td.channel a[href="/channel/<UC…>"]` → `span.name`, `div.subs` |

한 페이지 20건. 날짜 선택 UI가 있다(`2026.08.05.(수)`). **국가·기간·카테고리 파라미터는 URL
쿼리로 드러나지 않고 Nuxt 내부 상태에 있어서, 날짜를 바꿔 받으려면 추가 조사가 필요하다.**

### 차트 종류

| 경로 | 내용 |
|------|------|
| `/chart/video/` | 영상 (조회수 증가량 순) |
| `/chart/short/` | Shorts |
| `/chart/live/` | 라이브 |
| `/chart/ad/` | 광고 |
| `/chart/artist/` | 아티스트 |
| `/youtube-ranking/` | 채널 랭킹("한국 유튜브 인기 순위 - 일간") |

`sitemap.xml`은 국가별 채널 사이트맵을 제공한다(`/sitemap/channel/all/kr.xml` 등).

## 3. 실측 — 무엇이 올라오는가

**영상 차트 20건 중 11건이 브랜드 광고였다.** 헤드앤숄더 4건(1~4위, 증가량 3,027만/2,934만/
1,272만/1,248만), 하겐다즈 2건, 삼성 갤럭시 3건, 한국타이어 2건. 나머지는 aespa·BABYMONSTER·
TWS·KATSEYE 뮤직비디오다. 개인 창작물은 15위 "수요일은 비빔면 먹는날" 정도가 처음이다.

조회수 증가량으로 줄을 세우니 **광고 예산이 이긴다.** 한국타이어 영상은 게시일이 2026.04.22인데
지금 상위에 있다 — 넉 달 전 영상이 광고 집행으로 올라온 것이다.

Shorts 차트도 성격이 다르다. 글로벌이라 "The girl thought she saw Haaland", "No Oil vs Oil",
태국어 영상, 건설 공법 영상이 섞인다. 한국 커뮤니티에서 도는 짤과는 무관하다.

### 광고를 걸러낼 수 있는가 — 시도했고, 안 된다

`/chart/ad/`가 따로 있으니 영상 차트에서 빼면 되겠다고 생각해 대조했다. **겹치는 항목이 0건이다.**
`/chart/ad/`는 유튜브 광고 인벤토리를 다루고, 영상 차트의 헤드앤숄더·하겐다즈는 일반 영상으로
올라온 광고 콘텐츠다. 두 목록은 서로 다른 것을 센다.

HTML의 `chart__row--ad` 클래스도 답이 아니다. 그건 사이트 자체 광고(애드센스) 행이고, 1위
헤드앤숄더 영상의 행은 평범한 `chart__row`다.

남는 방법은 근사치뿐이다 — 제목 패턴(`_6s`, `_15s`, `(15초)`, `(30초)`)과 브랜드 채널 목록.
둘 다 목록 추격이라 **이 저장소가 이미 실패를 겪은 방식이다.**

## 4. 활용 방안

### 4-1. 소재 공급원으로는 쓰지 않는 게 맞다

우리 레이더가 찾는 건 "X에서 판정이 붙는 소재"다. playboard가 재는 건 "돈과 팬덤이 만든
조회수"다. 겹치는 구간이 거의 없고, 광고를 걸러낼 깨끗한 방법도 없다. 붙이면 화면 자리만
차지한다.

### 4-2. 프로젝트가 다르다는 점을 먼저 정리해야 한다

`~/Desktop/트랜드`가 **유튜브·쇼츠 조회수 랭킹 전담** 프로젝트다(홈 별칭 인덱스에 "실시간 영상
트렌드 / 유튜브 조회수 랭킹 / 쇼츠 트렌드 사이트"로 등록돼 있다). playboard는 정확히 그 주제다.
여기(커뮤니티 원문 레이더)에 넣으면 두 프로젝트가 같은 일을 하게 된다. **넣는다면 그쪽이다.**

### 4-3. 여기서 값이 있는 각도는 하나 — 교차 검증

소재를 공급받는 게 아니라, **이미 잡은 소재가 유튜브에서도 뜨는지 확인하는 용도**라면 값이 있다.
커뮤니티에서 돌던 이야기가 유튜브 상위에도 있으면 확산이 매체를 넘었다는 뜻이고, 이건 지금
`handoffs/0004`가 만들고 있는 교차 확산 감지와 결이 같다. 다만:

- 붙일 곳은 소재 목록이 아니라 **이미 선별된 항목의 근거 칸**이다.
- 유튜브 제목과 커뮤니티 제목은 표현이 달라 매칭이 어렵다. 해시태그(`ttags__item`)와 채널명이
  단서가 될 수 있지만 검증되지 않았다.
- 0004가 끝난 뒤에 얹어야 충돌이 없다.

### 4-4. 부수적으로 관찰 가치가 있는 것

- `/youtube-ranking/` 채널 랭킹의 급상승 — 소재가 아니라 **인물·채널 이슈**의 조기 신호일 수 있다.
- Shorts 차트의 **포맷** — 무엇이 먹히는 형식인지(길이·자막·훅 위치). 소재가 아니라 형식 참고.

## 5. 하지 않은 것 / 남은 질문

- 국가·기간·카테고리 파라미터를 찾지 못했다. 날짜별 아카이브를 받으려면 이게 필요하다.
- 갱신 주기를 재지 않았다(한 시점만 받았다). 수집 주기를 정하려면 두 시점 이상 비교해야 한다.
- 요청 예산을 정하지 않았다. 붙이기로 한다면 도메인당 간격과 하루 상한을 먼저 정해야 한다.

  드러났고, 소스를 늘리는 방향의 값을 확인하려고 사용자가 지목한 사이트들을 훑었다.
