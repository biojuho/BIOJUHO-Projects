# 핸드오프 0003 — 사연 게시판 확장과 82cook 차단 처리

- **상태:** OPEN
- **기획자:** Claude
- **추천 실행자:** Grok 또는 Qwen (파서 추가 반복 작업)
- **실행자:** (비어 있음)
- **작성일:** 2026-08-06

## 목표

사연·사건형 소재가 실제로 쌓이는 게시판을 추가하고, IP 차단된 82cook의 처리를 확정한다.

## 배경

직접 수집 7곳이 대부분 "베스트/유머" 목록이다. 성과가 좋았던 소재(가해자가 명확한 부당함,
예상을 뒤집는 낙차)는 베스트로 승격되기 **전에 원 게시판에 먼저 쌓인다.**

조사에서 확인된 사실:

- **보배드림**은 robots가 `Allow: /` 전면 허용이고 `best` 외에 `freeb`(자유)·`national`(국내이슈)·
  `strange`(신유머/이슈) 코드가 전부 HTTP 200이다. 사건형 서사가 여기서 먼저 뜬다.
- **뽐뿌 `hot.php`**는 핫딜이 섞여 노이즈가 크다. `/zboard/zboard.php?id=freeboard`(200)를
  병행하는 편이 사연 밀도가 높다. robots는 market 계열만 막는다.
- **루리웹**은 `/best/selection`(힛갤)이 200이지만, `community`·`userboard`는 게임·팬덤 잡담이라
  사연 밀도가 **오히려 낮았다**(실측). 넓히면 좋을 거라는 예상이 뒤집혔으니 무리해 늘리지 않는다.
- **82cook**은 2026-08-06에 443 연결이 거부되기 시작했다(IP 단위 차단). robots 자체는 허용이지만
  요청 빈도로 서버가 끊는 구조다.

## 범위

- **건드릴 것:** `direct_community_sources.py`(소스 목록·파서), 대응 테스트, 필요하면 `.env.example`.
- **건드리지 말 것:** 점수 계산, 커널 판정, 제외 필터, 화면 레이아웃.

## 단계

1. 보배드림에 `freeb`·`national`·`strange` 목록을 추가한다. **기존 `parse_bobaedream_best`가
   그대로 동작하는지 먼저 확인**하고(같은 테이블 구조일 가능성이 높다), 다르면 파서를 나눈다.
   `source` 키는 소스별로 구분해야 중복 제거가 작동한다.
2. 뽐뿌를 `hot.php` 단독에서 `freeboard` 병행으로 바꾼다. 두 목록을 각각의 소스로 등록한다.
3. 루리웹 `/best/selection`(힛갤) 추가는 **선택**이다. 넣는다면 사연 밀도를 실제 제목 20건으로
   확인하고 반환 섹션에 근거를 적는다. 밀도가 낮으면 넣지 않는 게 맞다.
4. **82cook 처리를 결정하고 근거를 적는다.** 셋 중 하나다 —
   ① 직접 수집에서 빼고 IssueLink 경유만 유지 ② 수집 주기를 별도로 크게(예: 1시간) 두기
   ③ 차단이 풀릴 때까지 `SourceBackoff`에 맡기고 그대로 두기.
   현재 상태를 실제로 확인한 뒤(`curl -m 12 https://www.82cook.com/entiz/enti.php?bn=15`) 판단한다.

## 수용 게이트

- `.venv/bin/python -m pytest automation/getdaytrends/tests -q` → 기존 921 유지 + 신규 통과.
- **추가하는 소스마다 robots.txt를 직접 확인**하고 결과를 반환 섹션에 붙인다(URL과 해당 줄).
- 각 파서를 실제 HTML로 검증해 몇 건이 파싱되는지, 조회·댓글·시각이 제대로 들어오는지 적는다.
- 서버 재기동 후 `/api/fast-viral`의 `source_health`에서 새 소스가 `true`인지 확인.
- `direct_source_total`이 새 소스 수만큼 늘었는지 확인(화면 분모는 서버 값을 쓴다).

## 금지사항

- **robots가 막은 경로에 요청하지 않는다.** 차단(403·430·연결 거부)을 헤더 위장·브라우저 자동화로
  뚫지 않는다. 이 저장소의 기준이다 — FMKorea·클리앙·네이트판·인스티즈·디시를 그 이유로 제외했다.
- **루리웹에 정렬·기간 파라미터(`orderby=`, `range=`, `custom_list=`, `cate=`)를 붙이지 않는다.**
  robots가 명시적으로 막는다.
- 소스를 늘릴 때 **수집 주기를 함께 검토한다.** 5분 주기로 일곱 곳을 두드리다 82cook이 끊겼다.
  소스가 늘면 사이트당 요청 간격이 유지되는지 확인한다.
- 되돌릴 수 없는 외부 행위 금지. 비밀키 노출 금지.
